# DECISION_LOG.md

Fortune-OS **意思決定ログ**（v0.2.5）。
計算方式・ツール・設定など、Fortune-OS の根幹に関わる選定を、
**候補→採用→理由→決定日**の形で記録する。思いつきでの変更を防ぎ、後から経緯を追えるようにする。

> 本ファイルは記録・監査文書であり、7レイヤータグの適用対象外（`CLAUDE.md` §2 の精神に準拠）。
> ツール選定・計算設定は Fortune-OS の根幹であり、**本人と協議の上で確定する**（AIが単独で決めない）。

---

## 記入フォーマット

```
### [番号] 論点
- 候補：A / B / C
- 採用：（採用したもの。未決定なら「未決定」）
- 理由：（採用理由。未決定なら検討中の観点）
- 決定日：YYYY-MM-DD（未決定なら「—」）
- 状態：確定 / 未決定・要協議
```

## 既に確定済み（v0.2・`knowledge/calculation_config.md` より遡及記録）

> 以下はv0.2で `calculation_config.md` に既に固定されていた設定。ログとして遡及的に記録する。

### D1 タイムゾーンの扱い
- 候補：JST固定 / 出生時の地方時
- 採用：**JST（UTC+9）固定。DSTなし**
- 理由：対象者の生年はいずれも日本のDST適用期間外（DSTは1948–1951のみ）。地方時は経度補正として別途「真太陽時補正」で扱う（D4参照）
- 決定日：2026-07-01（v0.2 `calculation_config.md` 制定時）
- 状態：確定

### D2 西洋占星術の黄道帯
- 候補：トロピカル / サイデリアル
- 採用：**トロピカル**
- 理由：現代の主流かつ本人の分析目的（意思決定支援）に照らし、体系間比較のため一貫した既定を先に置く必要があった。サイデリアルを使う場合は都度明示する運用とした
- 決定日：2026-07-01
- 状態：確定

### D3 西洋占星術のハウス方式
- 候補：Placidus / Whole Sign / Equal
- 採用：**Placidus（既定）**。比較のため Whole Sign を併記してもよい
- 理由：実務での使用例の広さを既定選定の基準とした。高緯度問題は本ケース（対象者の出生地）では非該当なため採用の妨げにならない
- 決定日：2026-07-01
- 状態：確定（ただし §1「未決定」参照 — Astro.com 等実ツール選定時に再確認する）

### D4 四柱推命の月柱切替基準
- 候補：節入り（節気）基準 / 旧暦の朔基準
- 採用：**節入り（節気）基準**
- 理由：四柱推命の一般的な実務慣行に合わせた。朔基準は四柱推命では非標準
- 決定日：2026-07-01
- 状態：確定

### D5 四柱推命の時柱：標準時 vs 真太陽時
- 候補：標準時（JST）のみ／真太陽時補正のみ／両論併記
- 採用：**標準時（JST）ベースを基本とし、真太陽時補正後の値も併記する（両論併記）**
- 理由：子刻・各刻の境界に近い場合、補正の有無で時柱の結論が変わりうるため、v0.3の実計算時点では無理に一本化しない
- 決定日：2026-07-01
- 状態：確定（ただし実計算で境界に該当した場合、D5-2として再協議する可能性あり）
