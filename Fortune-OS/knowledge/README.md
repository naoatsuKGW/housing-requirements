# knowledge/

Fortune-OS の**知識ベース層**（v0.1）。

`user/` が「対象者の事実」、`astrology/`・`psychology/`・`strategy/` が「その人への適用（分析）」であるのに対し、
`knowledge/` は**特定の人物に依存しない、汎用の参照知識**を置く場所である。

## 役割分担

| 層 | 内容 | 人物依存 |
|---|---|---|
| `knowledge/` | 占術・心理・戦略の**一般理論**（辞書・リファレンス） | なし |
| `astrology/` `psychology/` `strategy/` | 本人・配偶者への**適用と解釈** | あり |
| `user/` | 対象者の**一次情報** | あり |

分析エンジン（`astrology/` 等）は、`knowledge/` の理論を引いて `user/` の事実に適用する、という関係。

## 方針

- ここに書くのは**理論・定義・対応表**であって、本人への断定的解釈ではない。
- したがって `knowledge/` は**7レイヤータグの適用対象外**（`CLAUDE.md` §2）。理論を特定の人物に適用した時点で、適用先（`astrology/` 等）でタグが必要になる。
- 占術理論も「その体系ではこう言う」という記述に留め、科学的事実として提示しない（`docs/philosophy.md`）。
- 出典・体系名を明記する。諸説あるものは「諸説あり」と書く。

## 収録

- `astrology_reference.md` — 四柱推命・西洋占星術・六星系の基礎理論（骨子）
- `psychology_models.md` — Big5・認知科学・行動経済学・愛着理論・ユングの要点
- `strategy_frameworks.md` — 意思決定・キャリア・リソース配分の汎用フレーム
- `calculation_config.md` — **占術計算の設定規約（正典）**。JST・黄道・ハウス方式・節入り・真太陽時補正・出典書式。v0.3 実計算はこれに従う
