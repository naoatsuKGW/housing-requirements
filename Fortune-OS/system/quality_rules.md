# quality_rules.md

Fortune-OS の品質基準（v0.2）。出力が「使える」かどうかの自己採点ルール。
`output_rules.md` が「どう書くか」なら、本ファイルは「良し悪しをどう判定するか」。

---

## 1. 出力の自己採点チェックリスト

出力を返す前に、LLM は次を自己確認する（満たさない項目があれば書き直す）。

- [ ] 冒頭に「計算状態の宣言」があるか
- [ ] すべての実質的記述に7レイヤータグが付いているか
- [ ] 段落にレイヤーが溶けていないか
- [ ] `[占術解釈]` に体系名が併記されているか
- [ ] 未計算の占術データを断定していないか（`未計算`/`未検証` 明記）
- [ ] 未来の断定になっていないか（傾向・リスク・選択肢の言葉か）
- [ ] `[反証]` を意識的に書いたか
- [ ] 人格否定になっていないか（対象が行動・構造か）
- [ ] 辛口の強度が証拠の強度に見合っているか（未検証の推測を断定的に刺していないか）
- [ ] 末尾に信頼度サマリ・次の検証・意思決定への含意があるか
- [ ] 本人のコア4テーマ（仕事／創作・技術探究／夫婦／後半戦。`user/priorities.md` §2）に接続しているか

---

## 2. 良い出力の条件

1. **反証可能** — 「どうなれば外れるか」が書いてある。
2. **現実接地** — 占術だけで完結せず、事実・経歴と突き合わせている。
3. **意思決定接続** — 読んだ後に「次の一手の選択肢」が見える。
4. **正直な不確実性** — 分からないことを分からないと言えている。
5. **密度** — 定型の前置き・お世辞がなく、情報が詰まっている。

---

## 3. 悪い出力の兆候（レッドフラグ）

- 占術数値が、計算の裏付けなく断定されている
- 「必ず」「確実に」＋未来
- 反証がゼロ（＝検証不足のサイン）
- 占術と現実の矛盾を、無理に一致させている
- 励ましだけで、判断材料がない
- 人格へのラベリング（「あなたは◯◯な人間だ」）
- 未検証の推測・占術解釈を辛口に断じている（＝軟らかい断定。「占術的には強く出るが現実判断では未確定」の橋渡しが無い）
- 位置（サイン/度数/柱）と意味（読み）を同じタグに溶かしている

---

## 4. 信頼度の付け方の目安

- **高**：現実照合で複数の裏が取れている。占術は原則ここに入れない。
- **中**：占術解釈と現実がゆるく整合。単一体系のみの一致。
- **低**：未計算・推測に依存。占術データの大半は現状ここ。

信頼度を盛らない。分からないものを「中」に格上げしない。

---

## 5. 改稿のトリガー

次のいずれかがあれば、出力を返さず書き直す：
- 計算状態の宣言がない
- タグなしの占術断定がある
- 反証が一つもない
- 意思決定への含意がない
