# Fortune-OS

**個人用・統合分析OS（v0.1）**
占術・心理分析・人生戦略を、ひとつの意思決定支援システムとして統合するための Markdown ベースのプロジェクト。

---

## これは何か

Fortune-OS は「当たる占い」を作るためのものではない。

占術（四柱推命・西洋占星術・六星占術系など）、心理分析、そして現実の戦略立案を、**同じ土俵に混ぜずに分離したまま統合する**ための設計図（OS）である。

多くの占いプロンプトは、事実・計算・解釈・願望・断定をひとつの文章に溶かしてしまう。Fortune-OS はそれを禁止する。すべての記述は、次の7つのレイヤーのどれに属するかを明示しなければならない。

| レイヤー | 記号 | 意味 |
|---|---|---|
| 事実 | `[事実]` | 生年月日・出生地など、本人申告または一次情報で確認できるもの |
| 計算済み事実 | `[計算済]` | 実際に計算・出典確認したエフェメリス／命式などの数値 |
| 占術的解釈 | `[占術解釈]` | 占術体系の内部ルールに従った「読み」。体系名を必ず併記 |
| 推測 | `[推測]` | 上記から導いた仮説。占術外の常識的推論も含む |
| 現実照合 | `[現実照合]` | 本人の実際の経歴・行動・成果と突き合わせた結果 |
| 反証 | `[反証]` | その解釈・推測に反する事実、または外れる条件 |
| 信頼度 | `[信頼度:高/中/低]` | 上記を踏まえた、書き手自身の確信の度合い |

**未計算のものは必ず `未計算` / `未検証` と書く。** 天体位置・四柱・アスペクト・ハウス・大運・年運などを、計算せずに「それらしく」書くことは、この OS の最大の違反行為とする。

## 目的（ゴール）

このOSの最終目的は **「当てること」ではない**。

以下4領域の**意思決定支援**である。

1. **仕事**：MAミキサー／録音・音響技術者としてのキャリア戦略、組織との距離、独立適性
2. **創作・技術探究**：Dolby Atmos をはじめとする技術投資の優先順位づけ
3. **夫婦関係**：長期的なパートナーシップの維持と摩擦の言語化
4. **人生後半戦**：40代後半以降のリソース配分・撤退と集中の判断

占術は、これらを考えるための**視点の一つ**として使う。決定の代替物にはしない。

## 使い方

1. `system/system_prompt.md` を LLM のシステムプロンプトとして読み込ませる
2. `user/` 配下（本人・配偶者・優先度）を文脈として与える
3. 目的に応じて `templates/` から出力テンプレートを選ぶ
   - 全体像 → `templates/full_reading.md`
   - 年次レビュー → `templates/annual_reading.md`
   - 相性 → `templates/compatibility_reading.md`
   - 個別の意思決定 → `templates/decision_support.md`
4. 出力は必ず7レイヤーで分離されているか確認する

## ディレクトリ構成

```
Fortune-OS/
├── CLAUDE.md              ← 最優先ルール（LLM が最初に読む）
├── README.md              ← 本ファイル
├── ROADMAP.md            ← マイルストーン
├── CHANGELOG.md
├── docs/                  ← 思想・方法論・用語
├── system/               ← LLM への指示（プロンプト・ルール）
├── user/                 ← 分析対象者の一次情報
├── astrology/            ← 占術体系ごとの適用・解釈
├── psychology/           ← 心理分析の適用
├── strategy/             ← 現実の戦略立案
├── knowledge/            ← 人物に依存しない汎用の参照知識ベース
└── templates/            ← 出力フォーマット
```

## 設計上の禁止事項（ハードルール）

- 占術を**科学的事実**として提示しない
- 未来を**断定**しない（「〜になる」ではなく「〜の傾向／リスク／可能性」）
- 計算していない占術データを、あたかも計算したように書かない
- 医療・法律・投資について確定的な助言をしない
- 人格を否定しない。**行動・選択・パターン**を厳しく突くことは許容する

トーンは辛口でよい。本質を突く。ただし対象は「人格」ではなく「振る舞いと構造」である。
