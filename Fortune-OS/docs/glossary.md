# docs/glossary.md

Fortune-OS 用語集（v0.1）。

---

## 1. Fortune-OS 固有の用語

| 用語 | 意味 |
|---|---|
| 7レイヤー分離 | 事実／計算済／占術解釈／推測／現実照合／反証／信頼度 に記述を分ける規約 |
| 計算状態の宣言 | 出力冒頭で「何を計算し／何が未計算か」を明示すること |
| 現実照合 | 占術解釈を本人の実際の経歴・行動・成果と突き合わせる工程 |
| 外れログ | 占術解釈が現実と食い違った記録。捨てずに蓄積する |
| 未計算 / 未検証 | 実際に計算・確認していない占術データに付ける明示ラベル |

## 2. タグ一覧

- `[事実]` 一次情報で確認できること
- `[計算済]` 実際に計算・出典確認した数値
- `[占術解釈]` 占術体系のルールに基づく読み（体系名必須）
- `[推測]` 仮説（占術外の推論を含む）
- `[現実照合]` 実際の経歴・行動との突き合わせ結果
- `[反証]` 反する事実・外れ条件
- `[信頼度:高/中/低]` 確信度

## 3. 四柱推命（BaZi）用語（最小限）

> 詳細・実データは `astrology/bazi.md`。すべて現状 **未計算**。

- 四柱：年柱・月柱・日柱・時柱の4つの干支
- 日主（日干）：日柱の天干。本人を表す中心
- 通変星：日主から見た他の干の役割（比肩・食神・正財 等）
- 蔵干：地支に内蔵される天干
- 用神／喜忌：命式のバランスを取るために必要とされる五行
- 大運／年運：10年・1年単位の運気の流れ

## 4. 西洋占星術用語（最小限）

> 詳細・実データは `astrology/western_astrology.md`。太陽サイン以外 **未計算**。

- サイン：12星座
- ハウス：出生時刻・場所で決まる12の領域（時刻依存）
- アセンダント（ASC）：東の地平線に昇るサイン（時刻依存）
- アスペクト：天体間の角度関係（合・トライン・スクエア 等）
- シナストリー：2人のホロスコープを重ねる相性技法

## 5. 六星占術系用語（最小限）

> 詳細は `astrology/six_star_style.md`。**未計算**。

- 運命星：生年月日から割り出す基本星
- 運気サイクル：年ごとの運気の周期

## 6. 音響・本人領域の用語（文脈用）

- MA：Multi Audio／整音。映像作品の音声仕上げ工程
- Dolby Atmos：オブジェクトベースのイマーシブ音響フォーマット
- ミキサー：音を混ぜ、バランスを取る技術者／機材
